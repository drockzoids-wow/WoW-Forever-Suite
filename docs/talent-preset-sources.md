# Built-in talent preset sources

Reviewed November 16, 2026. The 54 public Icy Veins Forever guides expose 27 leveling schedules, 41 PvE and three world/PvP allocations (71 presets). All nine current classes and their three talent-tree specs are represented. Feral has separate hybrid, bear tank and cat damage PvE presets; it remains one talent tree. World variants for Beast Mastery, Marksmanship and Elemental appear on PvE URLs but are explicitly labeled by their actual purpose. Calculator links identify revision 70755; this is source provenance, not proof of native compatibility with the installed build.

Only game spell IDs, ordered point selections, source URLs and original short Suite labels/hints are shipped. No guide prose, artwork, scripts or calculator implementation is bundled. Leveling pages display a level-dependent prefix, so spell mappings were read from all calculator inputs and the complete 51-point schedule from the calculator link, rather than copying the currently visible ranks. PvE allocations were read at full size.

Each preset resolves every spell to exactly one live node/entry, checks rank limits and validates the entire order against live requirements. Missing or ambiguous identities reject the entire reference. Unknown requirements permit a read-only comparison but block learning/copying. PvE order is explicitly an allocation reference, not a recommended leveling path. Real talent purchases remain native and manual.

Existing per-class default specs remain the legacy reference when old character guide state has no preset ID. New guides and passive references retain the specific source/variant ID; removed or foreign IDs do not fall back to another spec. The source links below are also available in-game, offline, in each preview.

The Leveling Builds category contains the 27 point-by-point leveling schedules. The Endgame Builds category contains the 44 complete level-60 allocations, including PvE and World/PvP alternatives. Neither entry point names a selected spec; previews retain individual spec names and return to their matching category.
